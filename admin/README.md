# Custom CMS Admin Panel

This is the React + Vite frontend for managing the portfolio content. It acts as a custom headless CMS interfacing directly with the Python/FastAPI backend.

## Tech Stack
* **Framework:** React 18 + Vite
* **Routing:** React Router DOM v6
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **HTTP Client:** Axios
