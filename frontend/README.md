# Portfolio Frontend

This is the public-facing React application for Prasann Bellale's portfolio. It connects to the FastAPI backend to dynamically fetch projects, skills, blogs, and experience data.

## Tech Stack
* **Framework:** React 18 + Vite
* **Routing:** React Router DOM v6
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **SEO:** React Helmet Async
* **API Client:** Axios
